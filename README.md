# Zeeshan Fida — Personal Portfolio

A responsive, five-page personal portfolio built with HTML and CSS for my Tech SG Studio web development internship.

## Pages

- **Home** (`index.html`) — Introduction
- **About** (`about.html`) — My background and learning journey
- **Skills** (`skills.html`) — Skills I am developing
- **Projects** (`projects.html`) — My portfolio project
- **Contact** (`contact.html`) — Links to connect with me

## Features

- Five separate, connected pages
- Responsive layout for desktop and mobile
- Mobile navigation menu
- Semantic HTML and Flexbox
- Shared CSS file
- No JavaScript or frameworks

## Technologies

- HTML5
- CSS3

## Live Demo

[View my portfolio](https://stupendous-hummingbird-b84b47.netlify.app/)

## Run Locally

1. Download or clone this repository.
2. Keep all HTML files and `style.css` in the same folder.
3. Open `index.html` in a browser or with VS Code Live Server.
4. Use the navigation menu to visit the other pages.

## Profile Photo

To display my profile photo, place an image named `profile.jpg` in the same folder as `index.html`.
