# Zeeshan Fida — Personal Portfolio

A responsive personal portfolio created for Week 1 of the Tech SG Studio Web Development Internship.

This page introduces me and highlights the web development skills I am currently learning.

## Features

* Header with navigation links

* Semantic HTML elements

## Built With

* CSS3

No JavaScript or frameworks are used.

## How to Run

1. Download `index.html` and `style.css`.
2. Keep both files in the same folder.
3. Open `index.html` in a web browser.
